# Video: canción para aprender los números

Copia aquí tu archivo de video con el nombre exacto:

    aymara.mp4

Es decir, la ruta completa debe quedar así:

    aymara/assets/video/aymara.mp4

La página `lecciones/numeros/index.html` ya está lista y lo busca automáticamente en
esa ubicación (aparece en un panel desplegable "🎵 Video: canción para aprender los
números", justo arriba del selector de niveles). No necesitas tocar el código: solo
copia el archivo `aymara.mp4` en esta carpeta.
